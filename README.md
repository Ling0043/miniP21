# MiniP21
This is a R tool to check SDTM datasets
## use
Pass an SDTM dataset (e.g., TA, TE, TS, etc.) to the  `fct_validate_sdtm(df)` function. Upon execution completion, a validation report including a summary and specific error sources will be generated in the working directory. Reports are typically named following the convention: Domain Name + P21 Report + Timestamp.
